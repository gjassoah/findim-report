## Proposition 5.4: PROVED

Put f_t ∈ F, f_t(Y) = dim H^tY. By (5.3), f_t = χ(T^t[R]) and f_{t+1}(Y) = f_t(HY).
1. f_0,…,f_r are r+1 vectors in the r-dimensional space V. Let n be minimal with
   f_n ∈ span(f_0,…,f_{n-1}). Then n ≤ r. (If r=0, then f_0=0, every module is 0 and the claim is trivial.)
   Write f_n = Σ_{q<n} c_q f_q, an identity of functions on all modules.
2. Evaluate it at H^kY. This gives a_{k+n} = Σ_{q<n} c_q a_{k+q} for all k ≥ 0, where a_t = dim H^tY.
   So p(S)a = 0, where S is the shift and p(x) = x^n − Σ c_q x^q ∈ Q[x].
3. Write p = x^κ g with g(0) ≠ 0, so κ ≤ n. If Y has finite extinction time, then S^N a = 0 for large N.
   The annihilator ideal of a in Q[x] contains gcd(x^N, p) = x^κ. So a_t = 0 for t ≥ κ, and the extinction
   time is at most κ ≤ n ≤ r. ∎

## Proposition 5.11: PROVED

Write c_i(a,b) = [U_i(a), V_i(b)].

Key identity (F1), for i ≠ j and all r, s, b:
  c_j(r+s, b) = V_i(s+b)^{-1} c_i(r, s+b) V_i(s+b).

Proof of (F1). Put u = U_i(r), w = W_ij(s), v = V_j(b), u' = U_j(r+s), v' = V_i(s+b). The relations used are:
- [u,w] = u' and [w,v] = v';
- w commutes with v' (h = i ≠ j);
- u commutes with v and with u'; u' commutes with v'.

From these, w u w^{-1} = u'^{-1}u, w v w^{-1} = v'v and w^{-1}vw = v'^{-1}v. Then:
- u'vu'^{-1} = u w u^{-1}(w^{-1} v w) u w^{-1} u^{-1} = u w (u^{-1}v'^{-1}u) v w^{-1} u^{-1}.
- w(u^{-1}v'^{-1}u)w^{-1} = (u^{-1}u')v'^{-1}(u'^{-1}u) = u^{-1}v'^{-1}u.
- So u'vu'^{-1} = v'^{-1} u v' v u^{-1} = v'^{-1} u v' u^{-1} v.
- Hence [u',v] = v'^{-1} u v' u^{-1} = v'^{-1}[u,v']v'.

U_i(r)^2 = 1 is not used here.

Consequences:
1. V_i commutes with U_j and with V_j (i ≠ j), so it commutes with c_j(·,·). (F1) then gives
   c_j(a,b) = c_i(r, a+b−r) for all r and all i ≠ j. With |I| = 3, any two triples (i,a,b) and (i',a',b')
   with a+b = a'+b' are linked through at most one third index. So z_N is well defined.
2. Central: for i ∉ {h}, the element c_i commutes with T_h, U_h(r) and V_h(r). For i ∉ {j,k}, it commutes
   with W_jk(r), using the relations [W_jk, U_i] = 1 (i ≠ j) and [W_jk, V_i] = 1 (i ≠ k). Choose i
   accordingly; this is possible because |I| = 3.
3. z^2 = 1: put u = U_i(a), v = V_i(b) and z = [u,v]. Then uvu^{-1} = zv, and
   v = u(uvu^{-1})u^{-1} = z·uvu^{-1} = z^2 v, using u^2 = 1 and z central. ∎

Note: the proof uses |I| = 3 in an essential way, both for independence of i and for centrality with
respect to W.

## Lemma 5.16: PROVED (under the left-twist convention)

- Since α is a k-algebra automorphism, Ψ = _α(eR) is a k-central bimodule. As a right module,
  eR is a direct summand of R, hence finitely generated projective. So (R, Ψ) is selection data.
- e_q = α^q(e) are central idempotents and commute with each other.
- eR⊗_R Y ≅ eY via er⊗y ↦ ery, so HY ≅ _α(eY), naturally in Y.
- Induction: if H^jY ≅ _{α^j}(p_jY), then e acts on it as e_j, so e·H^jY = e_j p_j Y = p_{j+1}Y. The
  action is then twisted once more: r acts as α^j(α(r)) = α^{j+1}(r).
- Naturality: each step is natural.

With a right twist (eR)_α, the formula would change: there would be α^{-1}-twists of Y, and the formula
would need modification. The printed subscript on the left fixes the convention used above. ∎
