## Theorem 9.5 (Ext*_T(s,s) = k[τ], deg τ = 3; s nonprojective; End_T(s) stable = k)

**Verdict: PROVED** (all degrees), using Prop. 9.3 (proved above) and Lemma 9.4.

Step 1 (a resolution). Let R be the resolution of Prop. 9.3 and Q := T ⊗_C R, a complex of projective
T-modules (T ⊗_C Ce = Te, T ⊗_C Cf = Tf), bounded above. As complexes of vector spaces
T ⊗_C R = R ⊕ (DC ⊗_C R). Since D(DC ⊗_C P) ≅ Hom_C(P, C) naturally for f.g. projective P, H^{-i}(DC ⊗_C R) ≅
D H^i Hom_C(R, C), which by Prop. 9.3 is D(s^r) ≅ s for i = 2 and 0 otherwise. Hence H^0(Q) = s, H^{-2}(Q) is
one-dimensional, and H^i(Q) = 0 otherwise. A one-dimensional T-module is simple, rad T acts on it by zero, and
its C-module structure here is Tor_2^C(DC, s) ≅ s; so H^{-2}(Q) ≅ s as T-modules.

Step 2 (killing the extra cohomology). Inductively build bounded-above complexes of f.g. projectives P^{(m)}
with H(P^{(m)}) = s in degree 0 and s in degree d_m = −(3m+2), and P^{(0)} = Q: given P^{(m)}, there is a chain
map φ: Q[−d_m] → P^{(m)} inducing an isomorphism on H^{d_m} (map Q[−d_m] → τ_{≥ d_m}(Q[−d_m]) = s[−d_m] ≅
τ_{≤ d_m} P^{(m)} → P^{(m)} in D(T); since Q[−d_m] is K-projective this is a chain map). P^{(m+1)} := cone(φ)
has, by the long exact sequence, cohomology s in degree 0 and H^{d_m −2}(Q[−d_m]) = s in degree d_m − 3 =
d_{m+1}. Since cone(φ)^n = P^{(m)n} ⊕ Q^{n+1-d_m} and Q[−d_m+1] lives in degrees ≤ d_m − 1, the complexes
stabilise degreewise; the limit P is a projective resolution of s with
P^{-n} = ⊕_{i ≥ 0, 3i ≤ n} T ⊗_C R^{-(n-3i)}.

Step 3 (dimensions). Hom_T(T ⊗_C R^{-j}, s) = Hom_C(R^{-j}, s) is k for j = 0 and 0 for j ≥ 1 (Hom_C(Ce,s)=0).
So Hom_T(P, s) is k in each degree 3i (i ≥ 0) and 0 elsewhere; the differential is zero for degree reasons.
Hence dim Ext^n_T(s,s) = 1 if n ∈ 3ℤ_{≥0}, 0 otherwise.

Step 4 (ring structure). Q = P^{(0)} is a subcomplex of P with quotient P/Q. From 0 → Q → P → P/Q → 0 and
Step 1, H(P/Q) = s concentrated in degree −3, so P/Q is a projective resolution of s[3] and the projection
P → P/Q represents a morphism θ: s → s[3] in D(T), i.e. θ ∈ Ext^3_T(s,s). Precomposition with it,
Hom_T(P/Q, s) → Hom_T(P, s), is the map Ext^{n−3} → Ext^n, ξ ↦ ξ[3]∘θ (right multiplication by θ). On cochains
it is the inclusion with cokernel Hom_T(Q, s) = k in degree 0 only; all differentials vanish, so ·θ is bijective
Ext^{n−3} → Ext^n for n ≥ 3. Hence Ext^{3m} = k θ^m with θ^m ≠ 0 for all m, and Ext*_T(s,s) = k[θ]
(polynomial). Every nonzero element of Ext^3 is cθ, c ∈ k^×, hence a generator.

Step 5. s is not projective (Ext^3 ≠ 0; also dim s = 1 < dim Tf = 8). End_T(s) = k (s is one-dimensional),
and id_s does not factor through a projective since s is not projective, so the stable End is k.

## Corollary 9.18 (End_Λ(Λ ⊕ Z′): nine simples, infinite little finitistic dimension)

**Verdict: PROVED assuming (A14).** The link "Auslander–Reiten counterexample ⇒ infinite findim" is cited in

Let M = Z′ (nonprojective, Ext^i(M, M ⊕ Λ) = 0 for i ≥ 1 since M is a summand of Z), G = Λ ⊕ M, Γ = End_Λ(G)
with product γγ′ = γ∘γ′ (composition right to left). Hom_Λ(−, G) is a contravariant functor to left Γ-modules

   Hom(P_{n−1},G) → Hom(P_n,G); then pd X_n ≤ n + 1.
2. If pd X_n ≤ n, the n-th syzygy in the resolution 0 → Hom(M,G) → Hom(P_0,G) → … → Hom(P_n,G) → X_n, which
