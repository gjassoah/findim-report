## Lemma 6.1 (common denominators; killing morphisms)

Verdict: PROVED, modulo two standard facts about Verdier quotients (named below).

External facts used (sure of the statements):
- (V1) [Verdier; e.g. Neeman, *Triangulated categories*, Ch. 2; Krause, *Localization theory for
  triangulated categories*] W is a multiplicative system admitting a calculus of right fractions:
  W contains identities, is closed under composition, satisfies the right Ore condition
  (given u: X' -> X in W and f: Y -> X there are u': Y' -> Y in W and f': Y' -> X' with
  u f' = f u'), and every morphism qX -> qY is q(f) q(u)^{-1}.
  (The Ore condition is also immediate: complete u to X' -> X -> Z -> X'[1], let Y' -> Y -> Z
  be a triangle on the composite Y -> X -> Z, so u' has cone Z in S, and TR3 gives f'.)
- (V2) [Gabriel-Zisman; same references] For a calculus of right fractions, q(g) = q(g') iff
  g v = g' v for some v in W. In particular q(g) = 0 iff g v = 0 for some v in W.

Argument.
1. (Two denominators.) Let u_1: X_1 -> X, u_2: X_2 -> X be in W. By Ore applied to u_2 and u_1
   there are t: X'' -> X_1 in W and g: X'' -> X_2 with u_1 t = u_2 g =: u. Then u is in W
   (composite of W-maps), and since q(u_2) q(g) = q(u), we get q(g) q(u)^{-1} = q(u_2)^{-1};
   likewise q(t) q(u)^{-1} = q(u_1)^{-1}.
2. (Part 1.) Write gamma_i = q(f_i') q(u_i)^{-1} by (V1). By step 1 and induction on the number of
   morphisms there are u: X' -> X in W and maps c_i: X' -> X_i with u_i c_i = u. Then
   gamma_i = q(f_i') q(c_i) q(u)^{-1} = q(f_i' c_i) q(u)^{-1}; put f_i = f_i' c_i.
   (For zero morphisms the empty case is u = id.)
3. (Part 2.) By (V2) choose v_i in W with g_i v_i = 0. By step 1 there is v in W with
   v = v_i c_i for all i, so g_i v = g_i v_i c_i = 0.

Conventions: right fractions as in Sec. 6.1. Remark: S need only be a full triangulated
subcategory closed under isomorphism (as in the text); thickness is not needed here.

## Lemma 6.3 (directed algebras have pd <= n-1)

Verdict: PROVED.

1. Let N = sum of eps_j Lam eps_i over j > i. Since Lam = (+)_{j >= i} eps_j Lam eps_i and products
   (eps_l Lam eps_j)(eps_j Lam eps_i) land in eps_l Lam eps_i, N is a two-sided ideal, N^n = 0 (the
   index strictly increases with each factor), and Lam/N = k^n. So rad Lam = N, the eps_i are
   primitive, and the simple left modules S_i = Lam eps_i / N eps_i are one-dimensional.
2. For P_i = Lam eps_i, the multiplicity of S_j in P_i is dim eps_j P_i = dim eps_j Lam eps_i,
   which is 0 for j < i and 1 for j = i. So rad P_i has composition factors only S_j, j > i.
3. Downward induction: P_{n-1} = eps_{n-1} Lam eps_{n-1} = k, so S_{n-1} = P_{n-1}, pd 0. If
   pd S_j <= n-1-j for all j > i, then pd rad P_i <= n-2-i (pd of an extension is at most the max
   of the pd's, horseshoe lemma), so pd S_i <= n-1-i from 0 -> rad P_i -> P_i -> S_i -> 0.
4. A finitely generated module is finite-dimensional, hence has a composition series; by the
   extension bound, pd <= max_i pd S_i <= n-1.
5. Right modules: Lam^op with eps'_i = eps_{n-1-i} satisfies the same hypotheses
   (eps_j Lam^op eps_i = eps_i Lam eps_j).
Remark: for arbitrary (not f.g.) modules the bound also holds, since for a finite-dimensional
algebra the global dimension equals max pd S_i [Auslander; standard, sure].
