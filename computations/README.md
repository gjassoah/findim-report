# Computations

One directory (or file pair) per unit of work; each script has a header with the claim, cases,
conventions and author, and its output is saved next to it. Reproduction instructions are in the
subdirectories' own READMEs where present.

Note (2026-10-08): absolute file paths in saved outputs (e.g. Python tracebacks) were rewritten before
publication (repository path made relative, home directory written `~`); no other change was made to the
saved outputs.
