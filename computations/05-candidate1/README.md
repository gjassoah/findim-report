# Codex job 08

Claim: construct the one-factor Candidate 1 as actual bimodules and a
triangular module, then compute ordinary Ext through degree three.
Cases: two seeded primitive triples in GF(2^16), seeds 8082026 and 8082027.
Conventions: left modules, column maps, right twist u.a = u h_H(a),
characteristic two, and stable [1] = cosyzygy.
Status: the numerical conclusions are supported only in the recorded cases.
The final report is `../../audit/08-candidate1-codex.md`.

Use the system Python with SageMath. All Sage state is directed to this
folder; imported source files are read-only and bytecode writes are disabled.
Run from the repository root:

```sh
set -e
for case in 0 1; do
  python3 computations/05-candidate1/runner.py candidate "$case" > "computations/05-candidate1/case-$case.out" 2>&1
  python3 computations/05-candidate1/runner.py cone_profile "$case" > "computations/05-candidate1/W-$case.out" 2>&1
  python3 computations/05-candidate1/runner.py finish "$case" > "computations/05-candidate1/finish-$case.out" 2>&1
  python3 computations/05-candidate1/runner.py normalisation "$case" > "computations/05-candidate1/normalisation-$case.out" 2>&1
  python3 computations/05-candidate1/runner.py profile "$case" > "computations/05-candidate1/profile-$case.out" 2>&1
  python3 computations/05-candidate1/runner.py ext "$case" > "computations/05-candidate1/ext-$case.out" 2>&1
done
```

Stop the loop if a stage fails; later stages require its checked output.
`finish` reuses `N-raw-*.sobj` and `cosyzygy-*.sobj` checkpoints if present.
Remove those generated checkpoints first for a complete reconstruction of N.
The profile cache records and checks the SHA256 of its actual cone input.

`candidate.py` constructs minimal bimodule covers and transfers the supplied
bar cocycle by an explicit contracting homotopy. `finish.py` constructs N,
the two normalised lifts, F, its evaluation, and an actual diagonal map.
`cone_profile.py` computes W from actual T-modules. `profile.py` computes
stable Hom(s,F tensor s) and delta^0. `ext.py` constructs ordinary minimal
Lambda-projective covers and both Hom complexes, without asserting any
expected Ext dimension. It also checks that F is projective on both sides.

`runner.py` changes only matrix arithmetic dispatch: multiplication uses
exact sparse matrices, and concatenation converts to a common dense type.
It applies these changes to the Python syntax tree in memory; the displayed
mathematical code remains readable. `benchmark.out` checks agreement of
classical, Karatsuba and sparse products in the same field. Direct execution
of the unadapted scripts may be very slow or encounter Sage's dense/sparse
concatenation limitation.

The `Timeout (0:01:00)!` lines in some outputs are diagnostic stack samples
from Python's repeating faulthandler timer, not a time bound or a failed
mathematical assertion. Completion is recorded in the case JSON.

The system-size bound is 100000 scalar unknowns per vector linear solve.
Independent right-hand sides use the same coefficient matrix; their entries
are not flattened into a larger coupled system. The JSON records coefficient
matrix sizes at the guarded operations. No Ext degree above three is
computed; the separate W calculation needs shifts through four.

`normalisation.py` separately checks literal equality and stable nonvanishing
of the two evaluated lifts. `summarise.py` collects completed receipts and
writes `summary.json` and `SHA256SUMS`.

Saved Sage objects contain the actual cone, N, maps, F, and the ordinary
resolution/Hom matrices. JSON records parameters, dimensions, ranks and
system sizes. No output from job 07 supplies a mathematical premise.

The SageMath data files (`*.sobj`) written by these scripts are not included in the repository; they are
regenerated by running the scripts. Their SHA-256 checksums, where recorded, are in `SHA256SUMS`.
